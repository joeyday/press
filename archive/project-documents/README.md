# Saved Agent project documents

These are readable copies of project-specific documents found under `.local`.
The copies were made on October 1, 2026. The original files were left unchanged.

## Contents

- `tasks/` — 31 saved task and planning briefs. Some subjects have both a
  descriptive filename and a numbered filename. These briefs do not record
  completion status and are not a live task list.
- `commit-message.txt` — the saved commit-message draft about keeping
  article-aware sorting while displaying titles unchanged.

These copies are snapshots, not automatically synchronized with the originals.
Replit runtime-state files and bundled skill libraries were not copied.

The documents are under `.agents` because it is visible in this project's file
browser, while `.local` was not visible even with hidden files enabled. The site
generator skips dot-prefixed directories, so these Markdown documents will not
be published as website pages.
